# Little Craft Design

A small-business website for **custom cake toppers and party decorations**. This repository showcases front-end website development and visual design for a real-world small-business use case.

**[View the live website](https://alanmeireles.github.io/littlecraftdesign/)**

## Project overview

The website presents Little Craft Design's offerings and helps visitors explore the business online. It is also part of my web design and development portfolio.

## Technology and structure

- **HTML** for the website's structure
- Website styling and interactive page elements maintained within the project
- Static deployment with **GitHub Pages**
- Images and other visual assets in the repository

The main web page is `index.html`. Supporting assets and screenshots are organized into repository folders.
